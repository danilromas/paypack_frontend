PayPack Marketplace — Chrome extension v1.0

1) Download paypack-marketplace-extension.zip from your PayPack site:
   /api/extension/download/

2) Unzip to a folder (e.g. paypack-marketplace).

3) Chrome → chrome://extensions → enable "Developer mode".

4) "Load unpacked" → select that folder.

5) Click the extension icon:
   - Overview — status, quick import / copy link, counters
   - History — table of past imports (open / copy / delete)
   - Settings — PayPack URL, button label/color, feed & detail toggles
   - Help — short install notes + link to /extension/

6) Open a Facebook Marketplace listing — use the teal overlay button
   "BUY IN PAYPACK" above the seller message box (not inside Facebook DOM).

Default site URL: https://paypack.uno (change in Settings if needed).

For updates: remove the old extension (or Reload), unzip the new zip, Load unpacked again.
